Widget demo

Apertus chat widget on a third-party page

This page is not part of the Apertus demo UI — it stands in for a website where the chat widget has been embedded. Use the launcher button in the bottom corner to open the chat in a pop-up window.

The widget styles itself with namespaced, injected CSS, so the host page's button reset and stacking order above do not affect it. Configuration and embedding instructions are documented in the repository README under “Chat widget for third-party websites”.
